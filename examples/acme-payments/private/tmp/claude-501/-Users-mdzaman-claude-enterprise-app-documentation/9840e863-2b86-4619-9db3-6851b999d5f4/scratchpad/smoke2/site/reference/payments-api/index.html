    Acme Payments API

    Version 2.4.0 · OpenAPI 3.1.0

    Accept card and bank payments and issue refunds.

    Servers

    • https://api.acme.example — Production
    • https://sandbox.api.acme.example — Sandbox

    Authentication

    Security schemes
    NameTypeDetailsDescription
    bearerAuthhttpHTTP bearer tokenSecret API key, sent as a bearer token.

    Payments

    Create, list and capture payments.

    • GET /v1/payments List payments
    • POST /v1/payments Create a payment
    • GET /v1/payments/{payment_id} Retrieve a payment
    • POST /v1/payments/{payment_id}/capture Capture an authorized payment

    Refunds

    Refund captured payments in full or in part.

    • POST /v1/refunds Refund a payment
