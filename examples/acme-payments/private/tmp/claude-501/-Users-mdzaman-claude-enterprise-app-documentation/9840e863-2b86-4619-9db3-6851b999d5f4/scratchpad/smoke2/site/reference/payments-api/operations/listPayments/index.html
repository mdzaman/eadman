    GET /v1/payments

    List payments

    Returns payments, newest first.

    Parameters

    Query parameters
    NameTypeRequiredDescriptionDefault / allowed values
    limitintegeroptionalMaximum number of payments to return.
    • Default: 20
    • Minimum: 1
    • Maximum: 100
    starting_afterstringoptionalCursor for pagination (a payment id).
    statusstring (PaymentStatus)optionalOnly return payments with this status.
    • Allowed: pending, succeeded, failed, refunded

    Responses

    200 OK

    A page of payments.

    Content type: application/json

    200 OK response body (application/json)
    NameTypeRequiredDescriptionDefault / allowed values
    dataarray of Paymentrequired
    data[].idstringrequired
    data[].amountintegerrequired
    data[].currencystringrequired
    data[].statusstring (PaymentStatus)required
    • Allowed: pending, succeeded, failed, refunded
    data[].customer_idstringoptional
    data[].capturedbooleanoptional
    data[].created_atstringrequired
    • Format: date-time
    has_morebooleanrequired

    Security

    Requires bearerAuth — HTTP bearer token.

    Code samples
