    POST /v1/refunds

    Refund a payment

    Refunds a captured payment in full, or in part when amount is set.

    Request body

    Required. Content type: application/json.

    Schema: RefundCreate

    Request body (application/json)
    NameTypeRequiredDescriptionDefault / allowed values
    payment_idstringrequired
    amountintegeroptionalAmount to refund in minor units. Defaults to the full captured amount.
    reasonstringoptional
    • Allowed: duplicate, fraudulent, requested_by_customer

    Responses

    201 Created

    Refund created.

    Content type: application/json

    Schema: Refund

    201 Created response body (application/json)
    NameTypeRequiredDescriptionDefault / allowed values
    idstringrequired
    payment_idstringrequired
    amountintegerrequired
    statusstringrequired
    • Allowed: pending, succeeded, failed
    created_atstringrequired
    • Format: date-time

    400 Bad Request

    Error.

    Content type: application/json

    Schema: Error

    400 Bad Request response body (application/json)
    NameTypeRequiredDescriptionDefault / allowed values
    codestringrequired
    messagestringrequired

    Security

    Requires bearerAuth — HTTP bearer token.

    Code samples

    curl

    curl -X POST 'https://api.acme.example/v1/refunds' \
  -H "Authorization: Bearer $API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{
  "payment_id": "string"
}'

    JavaScript

    const response = await fetch("https://api.acme.example/v1/refunds", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    "payment_id": "string"
  }),
});
const data = await response.json();
console.log(response.status, data);
